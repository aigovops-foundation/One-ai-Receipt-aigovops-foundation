# IP and licensing policy

Code is Apache-2.0. Specifications and documentation are CC BY 4.0. Normative specifications require royalty-free, implementation-friendly patent commitments from contributing organisations (the OVERT covenant pattern is the model). Trademarks — "One Receipt", the Foundation's marks, Wren — are separately governed and never imply certification.

Implementations may state "One Receipt v0.2 syntax-conformant" only after passing the published vectors for the identified version; "interoperability-tested" only after a public interoperability event; never "certified". Conformance is a statement about an implementation of this protocol, not about the AI system behind it.
