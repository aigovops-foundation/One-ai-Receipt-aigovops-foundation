# Practitioner program — OR-100 to OR-600

The café's ladder (100 Begin · 200 Retrofit · 300 Hold · 400 Prove) already teaches the four gates on real corpus cases. One Receipt adds the evidence layer to each rung and two rungs above it for the people who will run logs, assess and review. Every level is one hour, ends in something a stranger can check, and sends the practitioner back to the community with a mark. Credentials are for **people**, never for systems — the ADR-0001 line holds.

| Level | Name | One hour of practice | The mark |
|---|---|---|---|
| **OR-100** | Read a receipt | Open a receipt from the vectors; find the four critical predicates; read `limitations` aloud; say what it proves and what it does not | Wren Card with the receipt id |
| **OR-200** | Emit one | From the 200 worksheet's CI step: `one-receipt emit` on a real corpus case at OR-1; verify it; commit the id as a `One-Receipt:` git trailer | A receipt a host verifies on Thursday |
| **OR-300** | Hold and register | Wire a hold decision into a `policy-decision` receipt; register it with `one-receipt-log-lab`; read the inclusion proof; watch the verified level become OR-2 | A graph with a hold in it |
| **OR-400** | Verify a stranger's | Verify a receipt you did not make, offline, with only the public key; then with the log; explain why the verified level is what it is | The first external verification |
| **OR-500** | Witness and assess | Run a witness in an anti-equivocation drill; sample receipts as an assessor-in-training with the public methodology; write a finding, including a negative one | A published drill result |
| **OR-600** | Review with authority | Take a `challenge` receipt through `review` to `remedy` in the café's practice loop; sit as an observer with the Public Interest Council for one session | A review receipt with `reviewer_authority: override` |

Levels 100–400 map rung-for-rung to the existing practice repo (`practice/levels/*`); the receipt steps are added to those worksheets rather than creating a second ladder. Levels 500–600 are new and depend on Phase 1 (log-lab, methodology, council).

Spanish worksheets ship with the English ones; the ten-language target follows the coalition's regional co-chairs. No fee; no badge for systems; hosts mark, the ledger mints.
